## Overview

This project connects Strava activity data to a reproducible analytics workflow in the [GitLab repository](https://gitlab.com/sboissel1/strava-analytics). A Python pipeline refreshes activities from the Strava API, enriches runs with pace and heart-rate summaries, and writes CSV outputs for weekly and per-activity analysis. Results are published in two interactive dashboards—a [Streamlit app](https://strava-analytics-sboissel.streamlit.app/) for day-to-day exploration and a Tableau Public story for sharing training patterns more broadly.

## Approach

- Built a Python pipeline that refreshes Strava API tokens, downloads recent activities, and writes enriched CSVs for runs, rides, swims, and hikes
- Added run pace-bin summaries and a rolling seven-day activity export for recurring analysis
- Scheduled a weekly GitLab CI job to refresh committed data files on `main`
- Shipped a Streamlit dashboard that mirrors the Tableau training overview, hosted on Streamlit Community Cloud and fed by the same CSV outputs
- Published a Tableau story to explore training patterns and summary metrics
