## Overview

This project connects Strava activity data to a reproducible analytics workflow in the [GitLab repository](https://gitlab.com/sboissel1/strava-analytics). A Python pipeline refreshes activities from the Strava API, enriches runs with pace and heart-rate summaries, and writes CSV outputs for weekly and per-activity analysis. Results started as a Tableau Public prototype, then grew into a [Streamlit app](https://strava-analytics-sboissel.streamlit.app/) with much richer training, fitness, and race views on the same curated datasets.

## Approach

- Built a Python pipeline that refreshes Strava API tokens, downloads recent activities, and writes enriched CSVs for runs, rides, swims, and hikes
- Added run pace-bin summaries and a rolling seven-day activity export for recurring analysis
- Scheduled a daily GitLab CI job to refresh committed data files on `main`
- Published an early Tableau story to prototype training patterns and summary metrics
- Shipped a Streamlit dashboard on Community Cloud with deeper coverage—achievements, HR zones, shoe mileage, fitness trends, and race results—fed by the same CSV outputs
