## Overview

This project connects Strava activity exports to a structured analytics workflow: data preparation and analysis in the GitLab repository, with key findings presented in a Tableau Public dashboard.

## Approach

- Imported and cleaned Strava export data for consistent date, distance, and activity-type fields
- Built reproducible transformations to support recurring analysis
- Designed a Tableau story to explore training patterns and summary metrics
